## Objetivo

Tener la capacidad de crear formularios flexibles y reutilizables para todo tipo de aplicaciones.

## Al terminar esta práctica serás capaz de

- Crear un componente potente de entrada de texto adaptable, para reducir el tiempo en la creación de formularios.
- Detectar comportamiento en tiempo real para reaccionar a los datos ingresados por el usuario.
- Validar datos de acuerdo con tus necesidades.
- Personalizar el tipo de teclado y el flujo de trabajo en el orden del formulario.
- Ofrecer información o botones que ayuden al usuario a corregir datos.
- Crear un selector de fechas interactivo.
- Recolectar y enviar la información capturada en el formulario para su procesamiento.
- Ofrecer una buena experiencia de usuario al editar y reutilizar un formulario.

## Cómo abrir el proyecto

1. Clona el repositorio:

   ```
   git clone https://github.com/GonzaloVargas-12/JC-Form---Android-Studio.git
   ```

2. Abre Android Studio y elige **Open**, seleccionando la carpeta del proyecto.
3. Espera a que termine la sincronización de Gradle. La primera vez puede tardar varios minutos.
4. Ejecuta con el botón **Run** sobre un emulador o un dispositivo físico.

> El archivo `local.properties` no se incluye en el repositorio porque contiene la ruta del SDK de cada computadora. Android Studio lo genera solo al abrir el proyecto.
